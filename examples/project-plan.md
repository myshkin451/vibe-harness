# Example Project Plan

## Product

Build a small personal publishing site for essays, project notes, and public experiments.

## Users

- primary: the site owner
- secondary: readers who want to understand current projects and writing

## Stage

Prototype. The first goal is a usable publishing loop, not a polished platform.

## Stack Preference

Use a simple TypeScript web stack. Prefer boring tools and easy deployment.

## Definition Of Done

- home page lists recent writing
- one essay page renders from local content
- project can run locally
- future agents know where content, routes, and validation live

## Risks

- overdesigning the architecture before the first publishing loop
- losing product intent across sessions
- adding docs that no one updates

## Human Decisions

- visual taste
- public identity
- deployment account/secrets
