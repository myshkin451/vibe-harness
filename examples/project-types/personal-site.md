# Project Plan: Personal Site

## Product

Build a personal site for writing, projects, notes, and a lightweight public identity.

## Users

- the site owner
- readers who want to understand current work
- future agents maintaining content and UI

## Stage

First usable loop. The goal is publishing one essay and one project page locally.

## Stack Preference

TypeScript, simple web framework, markdown or MDX content, easy static deployment.

## Definition Of Done

- home page communicates the site identity
- writing index lists at least one essay
- project index lists at least one project
- local run/build commands are documented
- future agents know where content and routes live

## Risks

- over-polishing the homepage before content exists
- mixing private planning notes into public docs
- losing the intended voice and taste across sessions

## Human Decisions

- visual identity
- public wording
- domain/deployment credentials

## Recommended Harness Depth

Seed first. Add architecture only after the route/content structure exists.
